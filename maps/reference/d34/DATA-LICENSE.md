# Data licence

Proposed: the data of this package are released under the **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)** licence, the licence indicated by the MAPS project for its open datasets (task 6.4). The final choice belongs to Fondazione Gran Sasso Tech when the dataset is released as open data.

Attribution: «MAPS project – Fondazione Gran Sasso Tech, Gran Sasso Science Institute; elaboration on ISTAT data».

ISTAT data (municipal boundaries, population) are released by ISTAT under CC BY 4.0. The ISTAT travel-time matrix on TomTom graph is not included (see README.md, «Data not included»).

The code of the «maps-slo» library has its own licence (MIT), in the repository.
